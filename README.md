A fast, lean, read-only frontend for make.fun: a live bounty board with each bounty's live pot, entry fee and time left; bounty pages with live rewards and dates; column-driven leaderboards; and public account profiles. Vanilla HTML, CSS and JavaScript — no build step, no framework, no external assets. API answers are cached in memory and revalidated with ETags, long lists are paginated, and time-left labels refresh in place without rebuilding the page.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the board loads live data from the make.fun public API.
